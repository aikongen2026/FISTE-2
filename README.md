# Vestfjella Fiske STABLE 1.5 – sømløs kartmodus

Bygger på STABLE 1.4, men høyrepanelet og kartflyten er forenklet etter Mistra-versjonen.

## Nytt
- Klikk i kartet setter automatisk referansepunkt.
- Topp 10-soner oppdateres automatisk ved flytting/zoom.
- Klikk sone -> sluk, alternativer og fiskeråd vises direkte øverst til høyre.
- Kjent-vann-listen er beholdt, sortert beste først og zoomer fortsatt til valgt vann.
- Tilkomstfilter, Live GPS og NVE-dybdekart beholdt.
- Flere Kartverket-kartlag og terrengskygge.
- Stor informasjonsmengde er flyttet til nedtrekk; unødvendige kunnskaps-/innsiktspaneler er fjernet fra hovedvisningen.
- Analyse-kandidater redusert fra 180 til 120 for raskere respons.

Last opp innholdet i denne mappen til GitHub-repoets rot og deploy som før på Render.
