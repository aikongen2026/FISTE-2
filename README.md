# Vestfjella Fiske – REV 1

Egen ferskvannsapp for Vestfjella i Aremark, bygget med samme kart-/sidepanel-konsept som Fiste guiden, men med ørretfiske som hovedmotor.

## Innebygd i REV 1
- 10 kuraterte Vestfjella-vann fra den detaljerte fiskeoversikten.
- Live MET Norway-vær og rangering for Nå / +3 t / +6 t / neste kveld / i morgen tidlig.
- Ørret, abbor eller "alle ferskvannsarter".
- Metodefilter: sluk, spinner, mark og flue.
- De fire fluevannene håndheves som kun flue: Sætertjern, Midtre Ormtjern, Stubbetjern og Skogtjern 2.
- Egne fire prikkete ørretsluker med faktiske bilder og værstyrt anbefaling.
- NVE dybdekart som kartlag der data finnes.
- Standardkart og satellitt.
- Fangstlogg lokalt i nettleseren.
- Naviger-knapp til hvert vann.
- Offisielle Vestfjella-regler synlig hele tiden.
- PWA/offline-cache for grensesnitt og slukbilder.

## Viktig om temperatur
Appen viser lufttemperatur fra MET. Den later ikke som lufttemperaturen er vanntemperaturen i små tjern. Ørretrådene bruker temperatur konservativt.

## Kilder brukt i modellen
- Vestfjella Utmarkslag / Inatur: sesong, minstemål, redskapsregler og områdeinformasjon.
- NJFF: ørretens temperaturpreferanser og generelle råd for sluk/spinner/mark og vannlag.
- NVE: innsjø-/dybdedata.
- MET Norway Locationforecast: live vær og timeprognose.
- Den vedlagte Vestfjella-PDF-en: topp 10, tilkomst, fisketider, fluevann og dine fire slukvalg.
- Finnfisk/NVE-data: koordinater og vannidentifikasjon for de 10 vannene.

Scoren er beslutningsstøtte, ikke en fangstgaranti.
